# 통했다! 파티 🎄

연말 회식·미팅용 실시간 단체 게임. 질문이 뜨면 모두가 휴대폰에 답을 하나씩 쓰고,
**나와 같은 답을 쓴 사람 수만큼 점수**를 받습니다. 혼자만 쓴 답은 0점이라서 "남들이 쓸 것 같은 답"을 맞혀야 해요.

- 참가자: QR 찍고 → **이름만 넣으면 바로 참여** (로그인 없음, 새로고침·화면 꺼짐 후에도 자동 재접속)
- 진행자: 노트북을 프로젝터/TV에 연결하고 `/host` 화면으로 진행
- 질문 30개 기본 제공(회사생활 주제), 설정에서 자유롭게 고치고 `{회사}` 자리에 회사·팀 이름이 들어감
- "BBQ"와 "비비큐"처럼 같은 뜻인 답은 결과 화면에서 카드 두 개를 눌러 합치면 점수 재계산
- 띄어쓰기·영문 대소문자·문장부호 차이는 자동으로 같은 답 처리

## 50명 접속 괜찮나요?

네. 외부 패키지 없는 Node 서버 한 대로 동작하며, 같이 들어 있는 부하 테스트로 확인했습니다.

| 동시 접속 | 질문·결과가 모든 폰에 도착하는 시간 | 점수 계산 |
|---|---|---|
| 50명 | 최대 0.08초 | 정확 |
| 200명 | 최대 0.13초 | 정확 |

서버 메모리 약 70MB. 직접 확인: `npm start` 후 다른 터미널에서 `npm run loadtest -- 50`
(배포한 주소로도 가능: `node test/loadtest.js 50 https://내주소 3`)

> 진짜 병목은 서버보다 **행사장 와이파이**입니다. 회사 게스트 와이파이가 기기 수를 제한하는 경우가 있으니,
> 참가자들에게 LTE/5G(모바일 데이터)로 접속해도 된다고 안내하세요. 데이터 사용량은 아주 적습니다.

## 실행

```bash
cd party
npm start            # http://localhost:3000  ← 참가자
                     # http://localhost:3000/host  ← 진행자
```

### 인터넷에 올리기 (추천: Render, 무료)

1. https://render.com 가입 → **New + → Blueprint** → 이 저장소 선택 (루트의 `render.yaml`을 자동으로 읽음)
2. 몇 분 뒤 `https://tonghaetda-party.onrender.com` 같은 주소가 생김 → 진행자는 `/host` 로 접속
3. ⚠️ 무료 요금제는 15분 동안 아무도 안 쓰면 잠들고, 깨어나는 데 1분쯤 걸립니다. **행사 10분 전에 `/host`를 열어 두세요.**
   잠들 때 서버가 초기화되면 진행 중인 점수가 사라질 수 있으니, 행사 당일만 유료(Starter, 월 $7)로 올리면 더 안심입니다.

다른 곳(Railway, Fly.io, 사내 서버 등)도 `node server.js` 한 줄이면 됩니다. `PORT` 환경변수를 따릅니다.
**Vercel·GitHub Pages 같은 정적 호스팅에서는 실시간 연결이 안 되므로 동작하지 않습니다.**

## 진행 순서

1. `/host` → 행사 이름·회사 이름 입력 → **새 게임 방 만들기**
2. 화면의 QR을 찍으면 참가자 폰에 방 번호가 채워진 채로 열림 → 이름 입력 → 입장
3. **Space**(또는 ▶ 버튼) = 다음 단계: 질문 시작 → 답 받기(기본 40초) → 결과 공개 → 다음 질문
4. 결과 화면에서 같은 뜻의 답 카드 두 개를 차례로 누르면 합쳐짐 (먼저 누른 쪽 → 나중 누른 쪽)
5. 끝나면 **🏆 최종 결과** (시상대 + 순위)

단축키: `Space` 다음 단계 · `L` 순위 · `Q` 참여 QR 크게 · `Esc` 닫기
그 밖에: +15초, 질문 취소(점수 미반영), 즉석 질문, 건너뛰기, 참가자 내보내기(대기실에서 이름 위 ✕)

## 우리 회사 질문 넣기

진행자 화면 오른쪽 위 **⚙︎ 질문·설정**에서 한 줄에 하나씩 적으면 됩니다(진행자 브라우저에 저장).
답이 몇 개로 **잘 모이는** 질문이 재미있어요. 예:

- 올해 우리 팀 최고의 프로젝트는?
- {회사} 사내 식당 최고 인기 메뉴는?
- 우리 팀에서 커피를 제일 많이 마시는 사람은?
- 올해 {회사} 가장 큰 뉴스는?
- 대표님 하면 떠오르는 단어는?

## 구조

```
party/
  server.js          실시간 서버 (Node 내장 모듈만 사용, SSE로 상태 전송)
  public/play.html   참가자 화면 (휴대폰)
  public/host.html   진행자 화면 (프로젝터)
  public/qrcode.js   QR 생성 라이브러리 (MIT, Kazuhiko Arase)
  test/loadtest.js   동시 접속 부하 테스트
```

서버 상태는 `party/data/rooms.json`에 1초마다 저장돼서, 서버가 재시작돼도 같은 디스크라면 이어서 진행됩니다.
